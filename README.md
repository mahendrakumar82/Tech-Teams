# SpeakSense AI

A team-leader prototype for one recorded meeting. It reads who held the floor, whether people asked questions or challenged ideas, and whether the meeting followed the team charter. The coach then answers questions about what to say next time.

## Run it

```bash
npm install
npm run dev
```

Open the local URL Next prints. Choose **How to use**, then **Load sample team**, or upload your own transcript.

Add `?sample=1` to open the sample meeting immediately.

Instructions for another team leader are inside the app. The assignment write-up is under **Write-up**. Analysis stays in the browser.
